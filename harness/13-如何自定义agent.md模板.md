# 如何自定义agent.md模板
自定义AI Harness的agent.md模板需要根据具体项目需求进行调整。以下是一些关键的定制化建议：

自定义要素
1. 项目特定信息
- 修改项目名称和描述
- 更新功能特性列表
- 调整支持的任务类型和参数说明
2. API接口定制
- 根据实际接口路径修改API端点
- 更新请求/响应示例数据格式
- 添加项目特有的状态码说明
3. 部署配置调整
- 修改环境变量名称和默认值
- 更新安装部署步骤
- 添加项目特定的配置说明
4. 扩展性说明
- 根据项目架构更新扩展开发指南
- 添加实际的插件开发示例
- 提供具体的代码贡献指引

通过以上方面的调整，可以创建适合特定AI项目的个性化文档模板。
